# Safe Mechanic — Serious Point Games 🔒

A Unity game mechanic developed during my Game Programmer Internship at Serious Point Games. This project contains the implementation of a safe/lock interaction system built to industry standards in C#.

## About

This was developed as part of my internship work at Serious Point Games (Aug 2024 – Jan 2025). The task involved researching how similar mechanics are implemented in commercial titles, then designing and building a clean, reusable implementation in Unity that could be integrated into the wider game project.

Alongside the code, I produced low-level documentation to allow other team members to reproduce and extend the mechanic without needing to reverse-engineer the implementation.

## Features

- Safe/lock interaction mechanic
- Designed for reusability and easy integration
- Follows industry coding standards
- Accompanied by written documentation

## Tech

- **Engine:** Unity
- **Language:** C#
- **IDE:** Visual Studio / Rider

## How to Run

1. Clone the repository
2. Open in Unity (recommended: Unity 2021 LTS or later)
3. Open the scene from the `Assets` folder
4. Press Play to test the mechanic in the Editor
